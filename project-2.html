Face Mask Detection (CNN)

👤 Team Size: Solo
🏷️ Computer Vision

Project Overview

A convolutional neural network trained to classify whether a person in an image is wearing a face mask. The project covers the full pipeline from image preprocessing and feature scaling through model training and evaluation using standard classification metrics.

Try the Live Demo →

Approach

The model takes an input image, applies preprocessing and scaling, and passes it through a CNN to output a mask / no-mask classification. Performance was evaluated using standard classification metrics to validate reliability before deployment.
