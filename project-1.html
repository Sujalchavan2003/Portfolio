Amazon E-Commerce Sales Dashboard

👤 Team Size: Solo
🏷️ BI & Data Analytics

Project Overview

This project involved building an interactive Power BI dashboard analyzing over 2.8 million Amazon e-commerce sales records. The raw dataset contained significant inconsistencies and unnecessary fields, which required extensive data cleaning and transformation before it was reliable enough to analyze.

A large part of the work was simply figuring out what mattered: working through ambiguous, unstructured data to identify which fields were relevant, and independently determining a cleaning and analysis approach where the right path wasn't predefined.

What the Dashboard Surfaces

  • Revenue trends across time, category, and region
  • Key performance indicators (KPIs) for sales performance
  • Customer behavior patterns to support business insights and decision-making

Challenges

Scale and inconsistency: at 2.8M+ rows, even small structural inconsistencies compound quickly. Getting to a reliable, analysis-ready dataset meant systematic validation before any dashboard work could begin.

Ambiguity: the dataset didn't come with a predefined "right" way to clean or segment it, so a large part of the project was independently deciding which fields and cuts of the data would actually answer useful business questions.
